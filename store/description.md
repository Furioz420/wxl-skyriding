# Skyriding

Brings a server-authoritative Skyriding controller to the 3.3.5a client, including vigor abilities,
movement impulses, modern mount animation overrides, and steady-flight fallback.

Requires WXL Runtime, Modern M2, Spell Charges, compatible server protocol and spell data, and an
AdvFly-capable mount model. An optional AzerothCore reference is included; see the README first.
